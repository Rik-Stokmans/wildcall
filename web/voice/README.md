# web/voice — the narrator's recorded voice

Generated by `node tools/voice/generate.mjs` (see `tools/voice/README.md`); do not edit
by hand.

- `manifest.json`: `{"voice", "model", "format", "instructions", "generated", "lines": {"<id>": {"file": "<id>.ogg", "dur": <seconds>}}}`
- `<id>.ogg`: one Ogg/Opus clip per narrator line; `id` = first 16 hex characters of the
  SHA-256 of the line's exact UTF-8 text.

Until a pack has been generated this folder holds only this file, and the narrator uses
the system's speech synthesis.
