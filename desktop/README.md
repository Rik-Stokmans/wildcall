# Wildcall desktop shell

An Electron shell that starts the Go engine, waits for its `WILDCALL_LISTENING http://127.0.0.1:<port>`
line, and shows the game in a single window. Quitting (or closing the window) stops the engine, which
saves first (it exits on stdin EOF, `-parent-stdin`). Contract: `docs/contract.md` sections 6 and 7.

## Develop

Needs Go and Node 22.

    cd desktop
    npm install
    npm run dev          # runs `go run ./cmd/wildcall -dev -addr 127.0.0.1:0 -parent-stdin` from the repo root

Environment overrides (dev and tests only):

| Variable | Meaning |
| --- | --- |
| `WILDCALL_ENGINE_CMD` | full command replacing the bundled engine (quotes allowed) |
| `WILDCALL_ENGINE_PATH` | path to an engine binary replacing the bundled one |
| `WILDCALL_ENGINE_CWD` | working directory for the two above (default: repo root) |
| `WILDCALL_USER_DATA` | override the userData / save directory |
| `WILDCALL_SMOKE=1` | hidden window, no dialogs, verify page and bridge, exit 0 or 1 |

The shell always appends `-save <userData>` and, unless present, `-addr 127.0.0.1:0 -parent-stdin`.

F11 toggles fullscreen (Ctrl-Cmd-F on macOS via the View menu). The page can call
`window.wildcallDesktop.{quit, toggleFullscreen, isFullscreen, platform, version}`.

## Test

    npm run smoke        # unit tests + hidden-window Electron run against a stand-in engine

## Build

    npm run build:engine           # all targets; or --mac, --win, --target darwin-arm64,win32-x64
    npm run dist:mac               # dist/*.dmg and *.zip (arm64 + x64)
    npm run dist:win               # dist/*.exe (portable) and *.zip (x64)
    npm run dist                   # both

The engine is cross-compiled with `CGO_ENABLED=0` into `build/bin/<platform>-<arch>/` and packaged as
`<resources>/bin/wildcall[.exe]`. The icon (`build/icon.png`) is generated by `scripts/make-icon.mjs`;
electron-builder derives `.icns`/`.ico`. Builds are unsigned; no wine is needed to cross-build Windows.
CI (`.github/workflows/build.yml`) builds on native runners and attaches artifacts to `v*` releases.

## Where saves live

The `userData` directory of the app (`Wildcall`):

- macOS: `~/Library/Application Support/Wildcall`
- Windows: `%APPDATA%\Wildcall`

Delete that folder to start over. (Portable Windows builds still use `%APPDATA%`.)

## First launch of unsigned builds

- macOS: Gatekeeper blocks it on first open. Drag Wildcall to Applications, then right-click it and
  choose Open, then Open again. If it says the app is damaged (zip downloads), run
  `xattr -dr com.apple.quarantine /Applications/Wildcall.app`.
- Windows: SmartScreen shows "Windows protected your PC". Click More info, then Run anyway.
